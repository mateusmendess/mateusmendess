### 🚀 Projetos em destaque

**[HydrogenI BoxTwin 3D](https://github.com/mateusmendess/hydrogeni-boxtwin-showcase)** — 🏆 Vencedor do Desafio 3 do II Hackathon do Complexo Portuário do Itaqui
- Gêmeo digital 3D para medição automática do volume de fertilizantes em boxes portuários, com sensor ToF, Raspberry Pi operando offline e sincronização com a nuvem
- Atuo no desenvolvimento do sistema, da interface e do pipeline de CI/CD — projeto em fase de aceleração, rumo ao piloto no Porto do Itaqui
- 🔗 [Deploy ao vivo](https://hydrogeni-boxtwin-production.up.railway.app)
- `Flask` `SQLite` `JavaScript` `Raspberry Pi` `GitHub Actions` `Railway`

**[Aquawoman](https://github.com/mateusmendess/aquawoman)** — E-commerce completo em Django para uma loja real de produtos de limpeza
- Checkout com mapa interativo (Leaflet.js + geocodificação), integração Mercado Pago, painel admin, sistema de login de clientes
- 🔗 [Deploy ao vivo](https://aquawoman.up.railway.app)
- `Django` `PostgreSQL` `HTMX` `Tailwind CSS` `Mercado Pago`

**[DocuMind](https://github.com/mateusmendess/documind)** — Chat com PDFs usando RAG (Retrieval-Augmented Generation)
- Pipeline de IA com ChromaDB + LangChain + Groq (Llama 3.3), autenticação, histórico de conversas
- 🔗 [Deploy ao vivo](https://documind-ai.up.railway.app)
- `Flask` `PostgreSQL` `ChromaDB` `LangChain` `Groq API`

**[TaskFlow](https://github.com/mateusmendess/taskflow-webapp)** — Gerenciador de tarefas com notificações por e-mail e kanban
- Notificações automáticas via SendGrid, painel de perfil, UX mobile
- 🔗 [Deploy ao vivo](https://taskflow-webapp-production.up.railway.app)
- `Flask` `SendGrid` `APScheduler`
